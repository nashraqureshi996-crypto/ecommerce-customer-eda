# E-Commerce Customer EDA Dashboard

An exploratory data analysis (EDA) project and interactive Streamlit dashboard analyzing online store customer behavior and purchase patterns.

## Key Findings
1. **Length of Membership** is the strongest predictor of customer spending (correlation ~0.81).
2. **Time on App** positively correlates with yearly spending (~0.50), whereas **Time on Website** shows virtually no correlation.
3. Investing in mobile app features and customer retention programs yields the highest revenue impact.
